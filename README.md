# game-2B
Projeto de 2019 (13 anos)

Jogo criado para fazer uso de um headset compatível com Google Cardboard, usando de criatividade sobre como usar uma visão diferente em cada olho e um botão em cada lado da tela para fazer gameplay envolvente. Criado exclusivamente num celular Android da época sem assistência de um desktop, usando software básico.

A gameplay convidava o jogador a ler o texto na tela um olho por vez e usa coordenção motora rápidamente para escolher o botão correto. Mesmo jogando na mão, obter um novo recorde continua divertido.
Com no máximo 4 botões, a interface é absolutamente mínima.
